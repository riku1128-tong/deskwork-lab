選び方のポイント

1. HDMIのリフレッシュレート（30Hzか60Hzか）

4K出力でも、最大30Hzの商品と60Hzの商品があります。今回の5機種では、UGREEN Revodok 6-in-1が4K@60Hz、残りの4機種は4K@30Hzまでです。また、QGeemの2機種は、PC側のUSB-CポートがAlt mode（映像出力）に対応している必要があると説明されています。

2. PD充電の上限

PD充電の上限は、QGeem 7in1が最大85W、ほかの4機種は100Wです。UGREEN 5-IN-1はパソコンへの給電は最大95Wと説明されています。どの商品も、実際に給電できる量は使う充電器によって変わります。

3. ポートの数と種類

USB-Aの数と速度、データ用USB-Cの有無、SD/microSDカードリーダーの有無で選びます。カードリーダーが付くのはQGeem 7in1とUGREEN Revodok 1071の2機種です。今回の5機種にLANポートはありません。UGREENの3機種は、PD充電用のUSB-Cポートがデータ転送に対応していません。

4. 重さ（持ち運ぶ場合）

持ち運ぶなら重さも確認します。商品説明に書かれた重さは、QGeem 4in1が40g、QGeem 7in1が62g、UGREEN Revodok 1071が約110gです。

よくある質問

4K HDMIは60Hzで出せますか？

今回の5機種では、UGREEN Revodok 6-in-1だけが4K@60Hzに対応しています。ほかの4機種は4K@30Hzまでです。QGeemの2機種は、HDMI 2.0以下のケーブルではちらつきが出る場合があると説明されています。

PD充電はどれくらいのワット数まで使えますか？

QGeem 7in1は最大85W、ほかの4機種は100Wです（UGREEN 5-IN-1はパソコンへの給電は最大95W）。実際の給電量は使う充電器によって変わり、QGeemの2機種は充電の入力に38W以上、推奨は60W以上の出力のアダプタとされています。

つないでも画面が映らないのはなぜですか？

パソコンやスマホのUSB-Cポートが映像出力（Alt mode）に対応していないと、HDMIケーブルをつないでも映りません。QGeemの2機種の説明でも、Alt modeへの対応が必要とされています。お使いの機器のUSB-Cポートの仕様を確認してください。

まとめ

4Kモニターを60Hzで使いたいなら、5機種のうち4K@60Hzに対応するUGREEN Revodok 6-in-1が候補です。30Hzで足りるなら、カードリーダーが欲しい場合はQGeem 7in1かUGREEN Revodok 1071（今回の5機種で最も高い価格帯）、軽さ重視ならQGeem 4in1（40g）、価格を抑えたいならUGREEN 5-IN-1（今回の5機種で最も安い価格帯）が選びやすいでしょう。最新の価格は比較表と商品ページで確認してください。
